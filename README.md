## Getting Started

### Requirements

- Python 3
- [Pygame](https://www.pygame.org/)

```bash
pip install pygame
```

### Running the Game

```bash
cd chess
python3 gui.py
```

## Controls

| Input | Action |
| --- | --- |
| Click a piece, then a square | Move the piece |
| `U` | Undo |
| `R` | Reset |
| `F` | Flip board |

## Project Structure

```
chess/
├── board.py   # Board state and move logic
└── gui.py     # Pygame interface
```
